Privacy en opslag

Bijgewerkt op 29 september 2026. De controle van het webring-script staat nog open.

Over deze informatie

Deze pagina beschrijft de taalopslag en externe diensten die zijn vastgesteld in de bekeken websitebestanden. Er is geen volledige controle van alle cookies, netwerkverzoeken en externe scripts uitgevoerd. Daarom wordt hier niet beweerd dat de hele website cookie- of trackingvrij is.

Wat wordt in je browser bewaard?

De taalwisselaar bewaart NL of ENG onder de naam preferredLanguage in localStorage. Hiermee kan de website je taalkeuze bij een volgend bezoek gebruiken. Deze opslag heeft geen ingestelde vervaldatum en blijft staan totdat je de sitegegevens wist of je browser ze verwijdert. localStorage is iets anders dan een cookie: de browser stuurt deze waarde niet automatisch mee met ieder verzoek.

De melding op de startpagina

De melding verschijnt bij het laden van index.html. Sluiten wordt niet opgeslagen, dus bij een volgend bezoek aan die pagina verschijnt de melding opnieuw. Met de knop Privacy-informatie kun je haar opnieuw openen. De melding blokkeert geen externe diensten en is geen toestemmingsinstelling.

Hosting via GitHub Pages

GitHub Pages levert de bestanden van deze website. Volgens GitHub worden IP-adressen van bezoekers gelogd en bewaard voor beveiliging, ook als zij niet bij GitHub zijn ingelogd. De geraadpleegde Pages-documentatie noemt hiervoor geen vaste bewaartermijn.

Het externe webring-script

De homepagina verwijst naar https://digitaaltuintje.nl/webring.js. Bij het laden maakt je browser verbinding met die dienst; daarbij ontvangt de server je IP-adres en verzoekgegevens. De inhoud van het script, eventuele verdere verbindingen, opslag en bewaartermijnen konden nog niet worden gecontroleerd. Die details moeten nog bij de aanbieder worden nagevraagd.

Links naar andere websites

Links naar bijvoorbeeld GitHub en de oorspronkelijke bronnen openen andere websites. Daar geldt de privacy-informatie van die aanbieders.

Wat kun je zelf doen?

Je kunt de sitegegevens voor garnetsocean.nl verwijderen via de privacy-instellingen van je browser. Daarmee wis je ook de opgeslagen taalkeuze. Dit verwijdert geen loggegevens bij GitHub of andere aanbieders.
